# Contributing

Use Python 3.12 and the appropriate separate environment tier. Run `python scripts/verify_release.py --tests` for the public subset; full scientific archive regression is documented separately. Put UI presentation in dashboard modules and plant decisions in the existing typed services. Do not modify frozen evidence/models/configs in place. Experimental successors need new manifests, disjoint development/validation/final splits and explicit independent acceptance.

Keep OPTIMIZER-PREDICTED, DIGITAL-TWIN-REALIZED, SYNTHETIC-TARIFF, SYNTHETIC-MAINTENANCE and EXTERNAL-BENCHMARK evidence distinct. Never introduce API secrets or private machine paths. License selection remains with the project owner.
