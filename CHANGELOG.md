# Changelog

## v1.0.0 — 2026-10-01

First integrated deterministic public prototype: validated reduced-order digital twin (sim_v1.1), monitoring/energy analytics, independent predictive models and intervals, constrained robust/adaptive MILP, matched replay/independent checker, synthetic maintenance-aware planning, deterministic G0 supervisor and Streamlit operator dashboard.

Adds a separate public packaging profile, offline demo evidence, source provenance, permanent documentation, lightweight CI and release verification. Original Phase I–III scientific source/config/results/tests remain unchanged; prior simulator changelog is retained under docs/archive/frozen_root.

Known limitations: synthetic practice/tariff/maintenance, reduced-order physics, small populations, 24-hour health model, remaining duration/scheduling failures, no field maintenance evidence/ROI, no real authentication/ingestion/PLC/cloud control. Live G1 qualification pending; v1 uses deterministic G0.
