# v1.0.0 — Smart Industrial Energy Copilot

Deterministic simulation-backed industrial energy decision support: ML predicts, MILP decides, digital twin verifies, human approves. Includes plant/analytics/prediction, robust adaptive and synthetic maintenance scheduling, independent replay/checking, G0 supervision and seven-page Streamlit dashboard.

Frozen simulated evidence: matched example ~2.44% lower electricity / ~4.21% lower synthetic tariff cost; robust final feasibility 0/10→10/10; maintenance 16 services, 14 strict avoided, 2 undetermined, final feasibility 91.67%→87.50%; 81 scripted supervisory safety cases. Unlike effects remain separate; these are not field claims.

Demo: `python -m pip install -r requirements-demo.txt`, then `python -m streamlit run dashboard/app.py`. Four offline precomputed scenarios; no API credentials or retraining. Verification: `python scripts/verify_release.py --tests`. Full historical reproduction requires the retained scientific archive.

Limitations: reduced-order physics, synthetic practice/tariff/maintenance, small populations, duration errors, no real billing/maintenance ROI/industrial control. Live LLM qualification is pending and unnecessary for v1.0. Project license awaits owner selection.
